# 💍 Lavish Weddingz

✨ *An Indian Wedding Planning Website*

Lavish Weddingz is a web-based platform that helps users find, compare, and book the best wedding vendors with ease. It simplifies wedding planning through a smooth and user-friendly digital experience.


## 🚀 Features

* 🔍 Vendor Search & Filtering
* 💰 Price Comparison
* ⭐ Ratings & Reviews
* 📅 Online Booking System
* 📝 Wedding Blogs


## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Server:** XAMPP


## 👥 Users

* **Admin** – Manages system, vendors & bookings
* **Client** – Searches and books vendors
* **Vendor** – Handles profile & bookings


## 📌 Project Highlights

* Replaces manual booking system with digital platform
* Secure and efficient data handling
* 24/7 vendor access and booking
* Improved user experience
